# Ideias de artigos

Esta pasta reúne ideias encontradas durante a revisão de literatura que possam
contribuir para o ALPS ou para a dissertação.

## Como registrar uma ideia

1. Copie `modelo.md` para um novo arquivo.
2. Use um nome curto e descritivo, por exemplo:
   `metricas-de-contencao.md`.
3. Registre a referência completa ou o DOI/link do artigo.
4. Separe claramente o que o artigo afirma da sua interpretação.
5. Indique como a ideia poderia ser validada no ALPS.
